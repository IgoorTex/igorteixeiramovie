# Igor Teixeira — Site

Site institucional (Story Maker & Social Media), HTML estático com GSAP + Lenis.

```
public/
  index.html      página completa
  media/          logo, vídeos (v1–v7), posters e vídeo da gota
vercel.json       Vercel publica a pasta public/
```

## Deploy na Vercel
1. vercel.com → Add New → Project → importe este repositório.
2. Framework Preset: **Other**. Não precisa de build. Clique em Deploy.

## Editar contatos
No final de `public/index.html`, bloco `CONTACT` (WhatsApp, Instagram, e-mail).
